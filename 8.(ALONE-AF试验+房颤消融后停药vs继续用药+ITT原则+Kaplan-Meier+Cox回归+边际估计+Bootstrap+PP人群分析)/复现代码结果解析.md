### Schoenfeld公式详细推导过程

#### 核心样本量计算函数
```r
#' 对数秩检验样本量计算函数
#' 
#' @param p1 对照组事件率
#' @param p2 试验组事件率
#' @param alpha 显著性水平（双侧）
#' @param power 统计功效
#' @param allocation_ratio 分组比例（试验组:对照组）
#' @param dropout_rate 脱落率
#' 
#' @return 包含详细计算结果的列表
calculate_sample_size <- function(p1, p2, alpha = 0.05, power = 0.80, 
                                 allocation_ratio = 1, dropout_rate = 0) {
  
  # 步骤1: 计算效应量（风险比）
  hazard_ratio <- p2 / p1
  log_hr <- log(hazard_ratio)
  
  # 步骤2: 计算Z值
  z_alpha <- qnorm(1 - alpha/2)    # 双侧检验
  z_beta <- qnorm(power)           # 统计功效对应的Z值
  
  # 步骤3: 计算所需事件数（Schoenfeld公式）
  # E = (Z(α/2) + Z(1-β))² / (log(HR))²
  events_needed <- (z_alpha + z_beta)^2 / (log_hr)^2
  
  # 步骤4: 计算总体事件率
  r <- allocation_ratio
  overall_event_rate <- (p1 + r * p2) / (1 + r)
  
  # 步骤5: 计算样本量
  total_sample <- events_needed / overall_event_rate
  
  # 步骤6: 脱落率调整
  adjusted_total <- total_sample / (1 - dropout_rate)
  
  return(list(
    sample_size = adjusted_total,
    events_needed = events_needed,
    hazard_ratio = hazard_ratio
  ))
}
```

#### 现实参数计算步骤
```
--- 样本量计算详细步骤 ---
步骤1 - 效应量计算:
  风险比 (HR) = P2/P1 = 0.5
  对数风险比 log(HR) = -0.6931

步骤2 - 临界值计算:
  Z(α/2) = Z( 0.025 ) = 1.96
  Z(1-β) = Z( 0.8 ) = 0.8416

步骤3 - 所需事件数计算（Schoenfeld公式）:
  E = (Z(α/2) + Z(1-β))² / (log(HR))²
  E = ( 1.96  +  0.84 )² / ( -0.69 )²
  E =  7.85  /  0.4805
  E =  16.3 个事件

步骤4 - 总体事件率计算:
  分组比例 r = 1
  总体事件率 = (P1 + r×P2)/(1+r)
  总体事件率 = ( 0.2  +  1 × 0.1 )/(1+ 1 )
  总体事件率 = 0.15

步骤5 - 理论样本量计算:
  总样本量 = 所需事件数 / 总体事件率
  总样本量 = 16.3 / 0.15
  总样本量 = 109 人

步骤6 - 各组样本量分配:
  对照组样本量 = 54 人
  试验组样本量 = 54 人

步骤7 - 脱落率调整:
  脱落率 = 6 %
  调整系数 = 1/(1-脱落率) = 1/(1- 0.06 ) = 1.064
  最终总样本量 = 116 人
  最终对照组样本量 = 58 人
  最终试验组样本量 = 58 人
```
