# 1. 它要估计什么？（目标效应/估计量）

* **处理T ∈ {0,1}** （1=暴露/治疗，0=对照），协变量  **X** 。
* **倾向性评分** ：e(X)=P(T=1∣X)
* **重叠权重（Overlap Weights）**定义：

  ![1759148867322](image/重叠加权详细解释/1759148867322.png)

  * PS 接近 0 或 1 的个体 **权重趋近于0** （说明他们几乎只会进某一组， **外推性差** ，不适合比较）， **重心自动落在“重叠区间”** 。
* 它识别的目标人群是  **ATO（Average Treatment effect in the Overlap population）** ：

  τATO=E[ Y(1)−Y(0) ∣ X 位于重叠区]\tau_{\text{ATO}}
  =\mathbb{E}\big[\,Y(1)-Y(0)\,\big|\,X\text{ 位于重叠区}\big]**τ**ATO=**E**[**Y**(**1**)**−**Y**(**0**)****X** **位于重叠区**]
  直观理解： **在“无论给哪种治疗都说得过去”的那群病人中** ，治疗与对照的平均差异。

> 与常见估计量对比
>
> * **ATE** ：全人群平均处理效应（IPTW 常估计它）。
> * **ATT** ：治疗组平均处理效应（配重见 e/(1-e) 等）。
> * **ATO（OW）** ：聚焦临床可交换的“重叠人群”， **方差更小、稳健性更好** ，通常也更符合“共同决策”的临床问题。

---

# 2. 为什么 OW 能“更稳”？（性质）

1. **权重有界** ：wi∈[0,1]w_i\in[0,1]**w**i∈**[**0**,**1**]**，避免 IPTW 在 PS→0/1 时的**极端权重**与高方差。
2. **精确配平** ：若 PS 模型正确（如对数几率回归），OW 可使 **已入模协变量的加权均值在两组精确相等** （理论上 SMD=0）。
3. **有效样本量（ESS）**更高：ESS=(∑w)2/∑w2\mathrm{ESS}=(\sum w)^2/\sum w^2**ESS**=**(**∑**w**)**2**/**∑**w**2** 通常优于 IPTW。
4. **关注可交换人群** ：规避“阳性假设/可比性”最差的边界样本。

> 不是“天然双重稳健”
>
> OW 本身是 **基于 PS 的加权估计** ，一致性依赖 **PS 模型**正确。
>
> 若要“双重稳健（DR）”，需使用 **增广/校正版本** （Augmented/DR-OW）：在加权的同时再加入一个 **结局回归模型** ，只要二者有一个正确即可得到一致估计。

# 3. 具体怎么做？（操作步骤）

### Step 1 估计倾向性评分 e(X)

* 常用：logistic 回归 `glm(treat ~ x1 + x2 + ... , family=binomial)`；也可用 `gbm/xgboost` 等灵活模型（要防过拟合，交叉验证与可解释性并重）。

### Step 2 计算重叠权重 w

* 治疗组：w=1−ew=1-e**w**=**1**−**e**；对照组：w=ew=e**w**=**e**。
* 可做 **组内归一化** （用于展示/配平诊断），但做模型时一般用**原始权重**即可。

### Step 3 诊断“可比性”

* **SMD（标准化差异）** ：加权后各协变量 **|SMD|<0.1** 为宜；OW 理论上接近 0。
* **PS 分布重叠** ：两组直方图/密度图在重叠区域应充分。
* **ESS** ：太小提示信息不足/PS模型或设计有问题。

### Step 4 结局建模（给效应量）

* **二分类结局** ：加权逻辑回归/直接计算加权风险差、RR。
* **时间到事件** ：
* **加权 KM** 给 2 年累计发病率与 **绝对风险差（RD）** ；
* **加权 Cox** 给  **HR** （配合稳健方差）。
* **竞争风险** ：**Fine-Gray（亚分布风险）**可带权，得到  **SHR** 。
* **不确定性** ：优选 **稳健 Sandwich 方差** 或  **bootstrap** 。

# 4. 与其他 PS 方法横向比较（什么时候选 OW？）

| 方法                              | 权重                       | 目标效应      | 极端 PS          | 平衡                     | 说明                   |
| --------------------------------- | -------------------------- | ------------- | ---------------- | ------------------------ | ---------------------- |
| IPTW（ATE）                       | 1/e, 1/(1-e)               | ATE           | **敏感**   | 取决于PS模型             | 易爆权重、方差大       |
| 稳定化 IPTW                       | 比例缩放                   | ATE           | 略好             | 同上                     | 仍有大权重风险         |
| ATT/ATC 权重                      | 1, e/(1-e) 等              | ATT/ATC       | 中等             | 取决于PS                 | 针对特定目标人群       |
| **Overlap Weighting（OW）** | **1-e** ,**e** | **ATO** | **最稳健** | **理论上精确平衡** | 关注“可交换”重叠人群 |
| 匹配（PSM）                       | 非权重                     | 近 ATT        | 剪除边缘样本     | 依匹配质量               | 简单直观但效率损失     |

> 当你预见 **边界 PS 较多/极端权重问题** ，且临床问题关注“**谁都可给治或不治**那群人”的效果时， **优先选 OW** 。

# 5. 与“Fine-Gray/ Cox”的结合（生存与竞争风险）

### 5.1 加权 KM（2 年绝对风险/净临床获益）

* 直接用 OW 作为  **case weights** ，估计 2 年累计发病率 F^(2y)\hat F(2y)**F**^**(**2**y**)，两组取差得  **RD** ；
* 方差：Greenwood + delta 或  **bootstrap** （更简单可靠）。

### 5.2 加权 Cox（HR）

* `coxph(Surv(time, event) ~ treat, weights = w, robust = TRUE)`；
* **robust=TRUE/cluster(id)** 取得稳健 SE（权重下常规方差可能偏乐观）。
* 可加少量强先验协变量（如年龄、性别）提升精度；这不是“必要的因果调整”，而是 **效率增益** 。

### 5.3 竞争风险 Fine-Gray（SHR）

* `cmprsk::crr(ftime, fstatus, cov1=..., weights=w, robust=TRUE)`；
* `fstatus`: 0=删失，1=目标事件，2=竞争风险（如死亡/其他事件）。

# 6. 关键假设 & 易错点

1. **可交换性** ：给定 X 后无未测混杂；若担心遗漏，考虑  **DR-OW（增广重叠权重）** ：在带 OW 的同时加上一个 **结局回归** ，得到 **双重稳健** 。
2. **共性支持（positivity/overlap）** ：每个 X 下 0<e(X)<1；**极差重叠**时，OW 仍会把边界样本权重压到近 0，但这意味着你的结论**只对重叠子人群**有效（这本来就是 ATO 的定义）。
3. **PS 模型设定** ：含线性项、必要的非线性/交互（样条、分段、多项式）；错设会破坏配平。
4. **诊断** ：不要只看 p 值，要看  **SMD、PS 重叠、ESS** 。
5. **归一化** ：作图/配平诊断时通常做 **组内归一化** ；用于 `coxph/crr` 时可用 **原始权重** 。
6. **报告** ：明确“ **估计的是 ATO** ”，与 ATE/ATT 不同；给出配平前后 SMD 图（Love plot）、PS 重叠图、ESS。
