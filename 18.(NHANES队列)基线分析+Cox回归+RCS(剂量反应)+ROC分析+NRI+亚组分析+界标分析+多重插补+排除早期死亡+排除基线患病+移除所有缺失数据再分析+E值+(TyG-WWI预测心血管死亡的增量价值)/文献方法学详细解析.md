# 文献方法学详细解析：TyG-WWI与心血管死亡风险研究

## 📋 方法学总览

本文是一项基于NHANES数据库的前瞻性队列研究，旨在评估甘油三酯葡萄糖-体重调整腰围指数（TyG-WWI）对心血管死亡的预测价值。以下是研究采用的主要方法学框架：

### 🔬 研究设计

- **研究类型：** 前瞻性队列研究
- **数据来源：** 美国国家健康与营养检查调查（NHANES）1999-2018年数据
- **样本量：** 24,255名成年参与者（≥18岁）
- **随访时间：** 中位随访9.67年，共854例心血管死亡事件
- **抽样方法：** 多阶段概率抽样设计，确保全国代表性

### 📊 核心暴露变量

- **主要指标：** TyG-WWI = TyG × (腰围cm / √体重kg)
- **对照指标：** TyG、TyG-WC、TyG-WHtR
- **变量标准化：** Z分数标准化，便于效应大小比较

### 🧮 统计分析方法

#### 关联性分析

- **主分析模型：** 加权Cox比例风险回归模型
  - 粗模型：未调整协变量
  - 模型I：调整年龄和性别
  - 模型II：完全调整模型（年龄、性别、种族、教育、婚姻状况、贫困收入比、吸烟、饮酒、心血管疾病史等）
- **剂量-反应关系：** 限制性立方样条（RCS）分析（4个节点：5%、35%、65%、95%百分位数）
- **非线性检验：** 似然比检验和分段线性回归

#### 预测性能评估

- **ROC曲线分析：** 传统ROC曲线和时间依赖ROC曲线
- **模型比较：** DeLong检验（Bonferroni校正）
- **风险重分类：** 净重新分类改善（NRI）分析
- **最佳阈值：** Youden指数确定

#### 亚组与敏感性分析

- **亚组分析：** 年龄、性别、种族、教育等12个分层因素
- **敏感性分析：** 多重填补、排除早期死亡、排除基线CVD患者、E值计算
- **竞争风险分析：** 考虑非心血管死亡作为竞争事件

### ⚖️ 质量控制方法

- **加权方法：** 根据调查周期选择合适的MEC检查权重（WTMEC4YR/WTMEC2YR）
- **比例风险假设检验：** Schoenfeld残差法
- **共线性诊断：** 方差膨胀因子（VIF）评估
- **选择偏倚评估：** 标准化差异计算（阈值：10%）

### 💻 数据处理与软件

- **统计软件：** R语言（版本4.0+）
- **核心R包：**
  - `survival`：生存分析
  - `survey`：复杂抽样调查分析
  - `rms`：限制性立方样条分析
  - `pROC`：ROC曲线分析
  - `timeROC`：时间依赖ROC分析
  - `mice`：多重填补
  - `nricens`：净重新分类改善分析
- **缺失数据处理：** 完全病例分析 + 增强分类重编码

### 🎯 方法学优势

1. **大样本量**：提供充足统计效力
2. **全国代表性**：确保外部有效性
3. **长期随访**：捕获足够结局事件
4. **全面调整**：控制多重混杂因素
5. **多种验证**：多角度敏感性分析
6. **先进方法**：现代流行病学统计技术

### ⚠️ 方法学局限性

1. **观察性设计**：无法确立因果关系
2. **数据缺失**：可能存在选择偏倚
3. **残余混杂**：未测量因素影响
4. **反向因果**：亚临床疾病可能干扰
5. **人群特异性**：美国人群数据的外推性

```r
# R代码示例：TyG相关指标计算
calculate_tyg_indices <- function(data) {

  # TyG指数
  data$TyG <- log(data$triglyceride_mgdl) * data$glucose_mgdl / 2

  # TyG-WC指数
  data$TyG_WC <- data$TyG * data$waist_circumference_cm

  # TyG-WHtR指数
  data$TyG_WHtR <- data$TyG * (data$waist_circumference_cm / data$height_cm)

  # TyG-WWI指数（核心暴露变量）
  data$TyG_WWI <- data$TyG * (data$waist_circumference_cm / sqrt(data$weight_kg))

  return(data)
}
```

```r
# R代码示例：限制性立方样条分析
rcs_analysis <- function(data, var = "TyG_WWI") {

  library(rms)
  library(survey)

  # 创建设计对象
  nhanes_design <- svydesign(
    id = ~SDMVPSU,
    strata = ~SDMVSTRA,
    weights = ~sample_weight,
    nest = TRUE,
    data = data
  )

  # 拟合RCS模型（4个节点：5%, 35%, 65%, 95%）
  knots <- quantile(data[[var]], c(0.05, 0.35, 0.65, 0.95), na.rm = TRUE)

  model_rcs <- coxph(
    Surv(follow_up_time, cvd_death) ~
      rcs(data[[var]], knots) + age + sex + race_ethnicity +
      education + marital_status + PIR_category +
      smoking_status + drinking_status +
      chd_history + dm_history + hyperlipidemia_history +
      hypertension_history,
    data = data,
    weights = sample_weight
  )

  # 非线性检验
  model_linear <- coxph(
    Surv(follow_up_time, cvd_death) ~
      data[[var]] + age + sex + race_ethnicity +
      education + marital_status + PIR_category +
      smoking_status + drinking_status +
      chd_history + dm_history + hyperlipidemia_history +
      hypertension_history,
    data = data,
    weights = sample_weight
  )

  # 似然比检验比较两个模型
  anova_result <- anova(model_linear, model_rcs)

  return(list(rcs_model = model_rcs, linear_model = model_linear,
              nonlinearity_test = anova_result))
}
```

```r
piecewise_linear_analysis <- function(data, var = "TyG_WWI") {

  library(segmented)

  # 拟合初始线性模型
  initial_model <- coxph(
    Surv(follow_up_time, cvd_death) ~
      data[[var]] + age + sex + race_ethnicity +
      education + marital_status + PIR_category +
      smoking_status + drinking_status +
      chd_history + dm_history + hyperlipidemia_history +
      hypertension_history,
    data = data,
    weights = sample_weight
  )

  # 使用segmented包识别拐点
  segmented_model <- segmented(initial_model, seg.Z = ~data[[var]])

  # 提取拐点和分段斜率
  breakpoints <- segmented_model$psi[, 2]  # 拐点位置
  slope1 <- segmented_model$coefficients[2]  # 第一段斜率
  slope2 <- slope1 + segmented_model$coefficients[3]  # 第二段斜率

  return(list(breakpoint = breakpoints, slope1 = slope1, slope2 = slope2,
              segmented_model = segmented_model))
}
```

```r
# R代码示例：ROC曲线分析
roc_analysis <- function(data, indices = c("TyG", "TyG_WC", "TyG_WHtR", "TyG_WWI")) {

  library(pROC)
  library(survey)

  # 创建设计对象（注意：ROC分析通常不使用权重）
  roc_results <- list()

  for (index in indices) {
    # 计算ROC曲线
    roc_curve <- roc(data$cvd_death, data[[index]],
                     ci = TRUE, ci.alpha = 0.95)

    # 计算最佳阈值（Youden指数）
    youden_coords <- coords(roc_curve, "best", ret = c("threshold", "sensitivity", "specificity"))

    roc_results[[index]] <- list(
      auc = auc(roc_curve),
      ci_lower = ci.auc(roc_curve)[1],
      ci_upper = ci.auc(roc_curve)[3],
      optimal_threshold = youden_coords["threshold"],
      sensitivity = youden_coords["sensitivity"],
      specificity = youden_coords["specificity"]
    )
  }

  return(roc_results)
}
```

```r
calculate_standardized_difference <- function(included_data, excluded_data) {

  # 计算两组间每个变量的标准化差异
  std_diff <- list()

  # 连续变量
  continuous_vars <- c("age", "bmi", "waist_circumference")

  for (var in continuous_vars) {
    mean_included <- weighted.mean(included_data[[var]], included_data$sample_weight)
    mean_excluded <- mean(excluded_data[[var]], na.rm = TRUE)

    sd_pooled <- sqrt(
      (var(included_data[[var]], na.rm = TRUE) +
       var(excluded_data[[var]], na.rm = TRUE)) / 2
    )

    std_diff[[var]] <- abs(mean_included - mean_excluded) / sd_pooled
  }

  # 分类变量（使用克莱姆V统计量或其他适当方法）

  return(std_diff)
}
```
