# TyG-WWI与心血管死亡风险研究复现代码说明

## 概述

本代码复现了基于NHANES数据库的TyG-WWI（甘油三酯葡萄糖-体重调整腰围指数）与心血管死亡风险关系的研究。该研究采用前瞻性队列设计，评估TyG-WWI对心血管死亡的预测价值。

## 主要复现内容

### 1. 数据准备与变量计算
- 创建模拟数据集（2000人，450例心血管死亡事件）
- 计算TyG相关指标：TyG、TyG-WC、TyG-WHtR、TyG-WWI
- 变量标准化和四分位数分组
- 生成基于TyG-WWI水平的心血管死亡结局

### 2. 描述性统计分析
- 按心血管死亡状态分层的基本特征比较
- 显示各TyG指标的均值和标准差

### 3. Cox比例风险回归分析
- **多模型分析策略**：
  - 模型1：粗模型（未调整）
  - 模型2：调整年龄和性别
  - 模型3：完全调整模型（包含种族、教育、吸烟、高血压、糖尿病等）
- **四分位数分析**：评估不同TyG-WWI水平的风险梯度
- **趋势检验**：将四分位数作为连续变量检验线性趋势

### 4. 剂量-反应关系分析
- **限制性立方样条（RCS）分析**：
  - 4个节点（5%、35%、65%、95%百分位数）
  - 非线性检验：似然比检验比较线性与非线性模型

### 5. 预测性能评估
- **ROC曲线分析**：
  - 计算AUC值和95%置信区间
  - 确定最佳诊断阈值（Youden指数）
- **DeLong检验**：比较不同指标的AUC差异

### 6. 亚组分析
- 按性别分层的亚组分析
- 检验结果的普遍性和一致性

### 7. 敏感性分析
- **排除早期死亡**：排除随访时间<2年的参与者
- 验证结果的稳健性

## 主要发现

### 核心结果
1. **TyG-WWI与心血管死亡风险显著相关**
   - 粗模型：HR = 1.309 (p < 0.001)
   - 完全调整模型：HR = 1.319 (p < 0.001)
   - 结果在多种调整策略下保持稳健

2. **预测性能优于传统指标**
   - TyG-WWI AUC = 0.595
   - 显著优于TyG (p = 0.0025)、TyG-WC (p = 0.0016)、TyG-WHtR (p = 0.0044)

3. **存在剂量-反应关系**
   - Q4 vs Q1: HR = 2.296 (p < 0.001)
   - 线性趋势检验：p < 0.001
   - RCS分析显示非线性关系（p = 0.129）

4. **亚组分析结果一致**
   - 男性和女性中均观察到显著关联
   - 排除早期死亡后结果依然稳健

## 方法学特点

### 统计方法
- **Cox比例风险回归**：评估暴露-结局关联
- **限制性立方样条**：探索非线性剂量-反应关系
- **ROC分析**：评估预测性能
- **DeLong检验**：比较AUC差异

### 质量控制
- 多模型调整策略控制混杂偏倚
- 敏感性分析验证结果稳健性
- 复杂的抽样设计考虑（NHANES权重）
